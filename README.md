# 世界遺産検定アプリ — 音声認識改善版

## GitHub Pagesへの反映
1. ZIPを解凍します。
2. 中の `index.html` をGitHubリポジトリ直下（`main` / `/ (root)`）へアップロードし、既存の `index.html` を置き換えてCommitします。
3. PagesのHTTPS公開URLをiPhoneのSafariで開き直し、ページを再読み込みします。

## 音声回答の使い方
1. クイズ画面で「🎤 話して答える」をタップします。
2. マイク許可を求められたら許可します。
3. 「聞き取り中」と表示されたら、1〜4、A〜D、または選択肢の文言を短くはっきり話します。
4. 画面の「聞こえた声」と判定を確認します。認識が違う場合は画面の選択肢をタップして回答し直せます。
5. 聞き取りを止める場合は停止ボタンをタップします。

## 対応・制限
- Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`）を提供するブラウザで利用できます。
- iPhone Safariを含め、音声認識はOS・ブラウザ・ネットワーク・音声認識サービスの状態に依存します。Webページ側だけで全端末の認識を保証することはできません。
- API非対応、マイク拒否、通信エラー、無音などは画面に案内を表示します。音声が使えない場合も選択肢タップで通常どおり回答できます。
- 音声認識はユーザーがマイクボタンを押した直後に開始します。連続認識は使わず、1回ごとのプッシュ・トゥ・トーク方式です。
